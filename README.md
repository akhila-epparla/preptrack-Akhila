# PrepTrack — Placement Preparation Performance Analyzer

## Project Overview

PrepTrack is a Python-based application that evaluates a student's placement preparation performance. It collects student profile information, attendance, project completion status, profile verification status, and seven days of coding practice scores. The application analyzes the student's performance, classifies scores, calculates the average score, detects critical scores, and displays the student's final placement readiness status.

## Features Implemented

- Student profile input
- Attendance validation
- Yes-or-no input validation
- Seven-day practice processing
- Score classification
- Passed and failed practice counting
- Highest and lowest score detection
- Critical score detection
- Average score calculation
- Placement readiness evaluation
- Final report generation
